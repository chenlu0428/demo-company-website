# 企业静态官网 Demo
> 前端作品集项目 | 纯原生前端实现，无框架

## ✨ 项目介绍
本项目是一个中小企业品牌展示静态官网，使用原生 HTML5 + CSS3 + JavaScript 开发。页面采用响应式布局，自动适配桌面端、平板、手机移动端。包含企业网站常用模块：顶部导航栏、轮播Banner、产品展示区、企业简介、客户案例、联系我们模块。页面增加基础交互效果：导航栏滚动变色、轮播图自动切换、平滑滚动跳转，代码结构清晰，便于后续二次迭代与维护。

## 🛠️ 技术栈
- HTML5：语义化标签搭建页面结构
- CSS3：Flex + Grid 布局，响应式适配，过渡动画
- JavaScript(原生JS)：实现轮播、页面滚动交互、平滑滚动
- 部署：GitHub Pages 静态网页托管

## 🎯 项目亮点
1. 使用 HTML5 语义标签（header / nav / section / footer），代码可读性好，符合前端规范
2. 响应式设计，一套代码适配电脑、手机多终端
3. 原生JS手写轮播组件，不依赖第三方轮播库
4. 滚动交互：页面向下滚动，导航栏背景自动变化
5. 代码注释完整，命名规范，便于阅读与维护

## 📌 项目说明
- 项目定位：前端练习 & 作品集 Demo，适合外包静态官网接单展示
- 后续扩展方向：可增加表单提交、图片懒加载，或迁移至 Vue3 重构版本
